  `agent-ag2`, `agent-agno`, `agent-bot`, `agent-claude-sdk`, ...).
- Start from the repo README, then the backend folder you need.
- Desktop shortcut: point it at the repo root (or README) so it opens where
  exploration starts. Never write to the real Desktop in evals — use the
